# Java Practice

Basic to intermediate Java concepts practice — written while learning Core Java.
Each folder is one practical, with the `.java` source and expected output as a comment.

## Topics Covered
- **Conditional Statements**: if, if-else, else-if ladder, nested-if
- **Loops**: for, while, do-while, nested loops, break, continue
- **Patterns**: number patterns (increasing/decreasing)
- **Arrays**: traversal, sum/average, min/max, reverse
- **Switch Case**
- **OOPs Concepts**:
  - Objects & Classes
  - Method Overloading (instance & static)
  - Constructors (default, parameterized, copy, overloading)
  - Packages
  - `this` and `super` keywords
  - Inheritance (single, multilevel, hierarchical, hybrid)
  - Interfaces (default/static/private methods, interface extends interface, multiple inheritance)
  - Abstract Classes
  - Method Overriding
- **String & StringBuffer** operations
- **Wrapper Classes** (Boxing/Unboxing, Autoboxing/Autounboxing)

## How to Run
Each `.java` file can be compiled and run individually:
```
javac FileName.java
java ClassName
```

For folders with a `mypackage` sub-folder (Practical-37, Practical-38), compile the package file first:
```
javac mypackage/*.java
javac MainFileName.java
java MainFileName
```
