# PGDCA Study Hub

An educational web portal built for PGDCA classmates — a single-page site with
subject-wise study material and previous year question (PYQ) papers, made easy
to browse and access.

## Features
- Semester-wise subject listing with interactive modals
- Previous Year Question (PYQ) papers section
- Mobile-friendly design with a responsive hamburger menu
- Simple, fast, single-file HTML/CSS/JS build — no framework dependencies

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
